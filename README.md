# Onde alugar?

Comparação de custos de aluguel para apartamentos de dois quartos em **Belo Horizonte** e **Juiz de Fora**. Escolha uma cidade para consultar o mapa interativo, a classificação dos bairros e os valores estimados de aluguel, condomínio e IPTU.

**Acesse: [thainanst.github.io/htmlTemporario](https://thainanst.github.io/htmlTemporario/)**

As estimativas são baseadas em anúncios consultados em novembro de 2026 e podem variar conforme o imóvel. Confira os valores e demais taxas diretamente nos anúncios ou com a imobiliária.

## Como usar localmente

Abra o arquivo [index.html](index.html) no navegador e selecione a cidade desejada. Os dados estão em [bh.html](bh.html) e [jf.html](jf.html); não é necessário instalar dependências.

## Publicação no GitHub Pages

Os três arquivos HTML devem estar na raiz da branch publicada. Nas configurações do repositório, em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch e a pasta **/(root)** e salve.

No GitHub Free, o repositório deve ser público para usar o Pages. O site publicado é público mesmo quando o plano permite usar um repositório privado.
